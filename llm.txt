# ASCII-art CLI

> A self-contained Node.js CLI that renders a name as colored ASCII art in the
> terminal. This file is the project map for coding agents — read the briefing
> docs below before writing any code, then build to the contract in AGENTS.md.

Constraints in one line: Node.js 18+, CommonJS, **zero dependencies**, output
via ANSI escape codes only — no network, no external APIs. `AGENTS.md` is the
source of truth; this index only points you to it so you don't drift.

The CLI you are building:
`ascii-art --name "<text>" [--style <fire|matrix|ghost>] [--animate]`
Entry point lives at `bin/ascii-art.js`, with one small pure renderer per style
(`fire` default, `matrix`, `ghost`). `--name` is required.
